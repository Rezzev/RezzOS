1.Что это?

RezzOS - это легковесный дистриубтив на ядре linux который использует busybox вместо gnu и musl вместо glibc.
В готвом образе испрльзуется x11 и JWM, при желании вы можете скачать исходный код и вырезать самостоятельно ненужные для вас компоненты и редактировать build скрипт(build.sh),а затем запустить его.В системе есть свой пакетный менеджер pkg который устанавливает пакеты с репозитория RezzOS,также есть apk(НЕ ИЗ ALPINE),это тот же пакетный менеджер только установка пакетов идет из репозиториев alpine linux.

2.Зачем это?

RezzOS создан для обобучения работы с linux и програмированием на слабых компьюетрах без настравивания системы.

3.Что тут есть?

RezzOS не базирован ни на каком дистриубутиве, главные компоненты системы:
Linux-6.6.40,musl,busybox,runnit,x11,grub,JWM.
В системе присутсвтуют уникальные программы специальные для RezzOS,графические и консольные,примеры:
Rtop и rtopg - system monitor и графическая его версия.
Editor - минимальный встроенный редактор кода.
Rview - просмотр изоюражений.
Browser - минимальный встроенный браузер.
Settings - меню настроек системы(интернет,swap и др).

*это не все утилиты!*

некоторые компоненты программ могут не работать или работать плохо т.к система находится в разработке, просьба при обнаружении неисправности сообщить в телеграмм канал,в личные сообщения владельцу репозитория,issue.

все программы для графичского интрефейса разрабатываются на gtk3
