## Установка RezzOS 
*Этот файл ориентирован для примитивных пользователей*
Установка операционной системы занимает очень маленькое
количество времени,и вот как ее осуществить:

# Шаг 1: Что нужно?
Вам необходима флешком обьемом 
от 512 МБ,и ваш ПК с 64х битным процессором и 
1Гб ОЗУ.

# Шаг 2: Установка iso или сблока
Скачайте готовой ISO образ из
Github Relases или соберите его сами
по руководству из BUILD.md

# Шаг 3: Запишите ISO на вашу флешку
Это можнно сделать с помошью 
таких программ как: rufus(windows),
ventoy, balena ethcer  и др

# Шаг 4: Установка
Загрузитесь с флешки и выберете 
первый пункт в GRUB,
затем вы попадете в саму ОС.
Нажмите ПКМ по любому  месту и в 
выпадающем меню нажмите Install On Disk,
Дальше следуйте инструкции установщика и 
заполняя поля для ввода.
