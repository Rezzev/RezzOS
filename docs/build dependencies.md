# Fedora/RedHat:
-------------
```bash
dnf install gcc make flex bison bc openssl-devel elfutils-libelf-devel perl cpio gzip wget tar xorriso qemu-img mtools grub2-tools fakeroot
```
# Alpine Linux:
-------------
```bash
apk add build-base flex bison linux-headers elfutils-dev openssl-dev perl bc cpio gzip wget tar grub-bios xorriso qemu-system-x86_64 qemu-img fakeroot
```
# Ubuntu/Debian:
--------------
```bash
apt install build-essential flex bison libncurses-dev libssl-dev libelf-dev bc cpio gzip wget tar grub-pc-bin xorriso qemu-system-x86 qemu-utils fakeroot
```
# Arch Linux:
-----------
```bash
pacman -S base-devel flex bison bc openssl libelf cpio gzip wget tar grub xorriso qemu-desktop fakeroot
```
