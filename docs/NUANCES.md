# Important Notice

RezzOS is currently under active development and is not yet a fully finished product. As such, users should be prepared for possible bugs, instability, or incomplete functionality.

If you encounter any issues, we encourage you to report them via GitHub Issues or through the project’s Telegram channel so that they can be reviewed and addressed.

---

## Network Configuration After First Boot

After starting RezzOS on real hardware, you may notice that internet access is not available by default. This is expected in the current development stage.

To restore connectivity, you will need to configure the necessary network parameters manually through the operating system configuration utility, `rezzconfig`. This process typically takes only a few minutes.

Please open the configuration tool and enter the required values according to your network environment. After the parameters are set correctly, the system should be able to access the network normally.

---

Because RezzOS is still in development, it is strongly recommended that users:

- Exercise caution when using the system in production or critical workflows
- Report issues promptly when they are discovered
- Stay informed about updates and changes in the project documentation
